One line, under 200 characters, in which a dog explains why the homework got eaten — written for the [make.fun bounty](https://make.fun/bounty/u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c).

The program (`main.ts`, Node 22) writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt`. A model judge reads entries two at a time and keeps the funnier one, round after round, until one excuse is left standing.
